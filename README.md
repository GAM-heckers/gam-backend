# 청도 농가 도우미

수확물 사진을 바탕으로 상품 등록 초안을 만들고, 온라인 판매가 익숙하지 않은 농가가 핵심 정보만 확인·수정하도록 돕는 프로젝트입니다.

> **현재 시연 범위:** 사진 선택과 브라우저 미리보기, 명확히 표시된 데모 초안, 상품 정보의 백엔드 모의 미리보기 요청입니다. 실제 AI 사진 분석과 네이버 상품 등록은 연결되어 있지 않습니다. 사진 파일은 현재 백엔드로 전송하지 않습니다.

## 주요 흐름

1. 수확물 사진을 선택해 미리보기합니다.
2. 데모 초안을 채우거나 상품명, 판매 가격, 박스 수, 한 상자 중량을 직접 입력합니다.
3. 백엔드 미리보기 API에 요청하고 받은 모의 응답을 확인합니다.

사진만으로 판매 가격이나 정확한 중량을 확정할 수 없습니다. 모든 값은 사용자가 확인해야 하며, 데모 초안은 AI 분석 결과가 아닙니다.

## 폴더 구성

```text
Frontend/   사진 미리보기, 상품 초안 및 백엔드 미리보기 UI
backend/    상품 미리보기 모의 API
.github/    Copilot 프로젝트 지침
ideation.md 아이디어와 제품 방향
prd.md      제품 요구사항 정의서
```

## 실행 방법

### 프런트엔드

정적 JSON 파일이나 모듈 번들러가 필요하지 않지만, 브라우저에서 접근하기 쉽게 정적 서버로 실행할 수 있습니다.

```powershell
cd Frontend
py -m http.server 5500
```

브라우저에서 `http://localhost:5500`을 열고 백엔드 주소를 확인합니다. 화면 기본 주소는 `http://localhost:3000`입니다.

### 백엔드

```powershell
cd backend
npm install
npm run dev
```

기본 주소는 `http://localhost:3000`입니다. 다른 포트는 `PORT` 환경 변수로 지정할 수 있습니다.

## 백엔드 API

### 상태 확인

```http
GET /health
```

성공 응답:

```json
{ "status": "ok" }
```

### 상품 미리보기

```http
POST /api/smartstore/products/preview
Content-Type: application/json
```

요청:

```json
{
  "productName": "청도 반시",
  "price": 18000,
  "boxCount": 1,
  "weightKg": 5
}
```

현재 프런트엔드는 이 JSON 네 필드만 전송합니다. 선택한 사진은 전송하지 않습니다. API는 모의 판매자와 네이버 매핑 초안을 반환할 뿐, AI 분석 또는 네이버 상품 등록을 하지 않습니다.

## 연결 시 확인할 점

- 로컬에서 프런트(5500)와 백엔드(3000)를 각각 실행합니다.
- 브라우저에서 “연결 확인”을 누른 뒤 “백엔드 미리보기 요청”을 시험합니다.
- 프런트와 백엔드의 포트가 다르면 백엔드에서 프런트 출처를 허용하는 CORS 설정이 필요합니다. 현재 백엔드에는 CORS 미들웨어가 없습니다.
- Azure 배포 시 프런트엔드에서 사용할 HTTPS 백엔드 주소를 화면에 입력하고, 백엔드 CORS에 프런트엔드 주소를 허용해야 합니다.
- `boxCount`의 의미가 재고 수량인지 포장 박스 구성인지 담당자와 확인합니다.

## 실제 사진 분석으로 확장할 때

현재 미리보기 API만으로는 사진 분석이 불가능합니다. 실제 분석을 위해 백엔드에 이미지 입력 API와 모델 연동이 추가로 필요합니다. 이미지 업로드 방식, 허용 파일, 결과 필드와 신뢰도, 보관·삭제 정책을 먼저 합의해야 합니다. 사진으로 알 수 없는 가격·정확한 중량·원산지·인증 정보를 모델이 임의로 확정해서는 안 됩니다.
